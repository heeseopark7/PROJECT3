# adder_beh

**하는 일**: `{cout, sum} = a + b + cin`을 `+` 한 줄로 쓴 덧셈기. 합성 툴이 구조(어떤 덧셈기로 만들지)를 알아서 고른다. 기준선(baseline)이다.

**구조**: W+1비트로 확장해서 더하고, 맨 윗비트를 cout, 아래를 sum으로 자른다.

**왜 이렇게**
- `+`를 써도 되는 곳은 `adder_beh`, `mul_beh`, 테스트벤치 기대값뿐이다. 다른 데 `+`가 숨어 있으면 툴이 구조를 마음대로 정해서 비교가 무의미해진다.
- 포트(`i_a, i_b, i_cin, o_sum, o_cout`)를 모든 덧셈기 변형과 똑같이 둬서 `adder_top`에서 갈아 끼울 수 있게 했다.

**합성 가설**: 툴이 속도 목표에 맞춰 구조를 바꿀 수 있어서, 클럭 목표가 빡빡해질수록 RCA보다 덜 느려질 것 같다. (수치는 합성 리포트 나온 뒤에 판단)
