# mul_beh

**하는 일**: 부호 있는(signed) 두 수를 곱해서 2·A_W비트 전체 곱을 내는 곱셈기. 기준선이다.

**구조**: `o_p = i_a * i_b` 한 줄. 입력과 출력 포트를 `signed`로 선언해서 2의 보수 부호 곱으로 계산된다. 곱셈 구조(어떤 회로로 만들지)는 합성 툴이 고른다.

**왜 이렇게**
- `*`는 `mul_beh`와 테스트벤치 기준값 계산에서만 쓴다. 다른 곳에 곱셈이 숨어 있으면 툴이 구조를 마음대로 정해서 Array/Booth 비교가 무의미해진다.
- 출력 폭을 2·A_W로 두면 가장 큰 곱 (−2^(A_W−1))² = 2^(2A_W−2)도 잘리지 않는다.
- `mul_array_csa`, `mul_booth_csa`와 포트(`i_a, i_b → o_p`)를 똑같이 둬서 `mul_top`에서 갈아 끼울 수 있다.

**합성 가설**: 툴이 속도 목표에 맞춰 부분곱 압축과 최종 덧셈 구조를 고를 것이다. 구조형(Array/Booth)이 BEH와 얼마나 다른지, 아니면 툴이 비슷한 구조로 재구성하는지가 M1 측정의 질문이다.
